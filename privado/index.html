Entra con tu clave de GitHub. Tus archivos se leen en vivo desde tus repositorios privados: no se guardan en este sitio y GitHub comprueba que la clave sea tuya.

Crear tu clave (una sola vez)
  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: «vhrs privado». Vencimiento: el que prefieras (90 días es buen equilibrio).
  3. Repository access: All repositories.
  4. Permissions → Repository permissions → Contents: Read-only (Metadata se agrega solo).
  5. Generate token, cópialo y pégalo arriba.

Es de solo lectura: con ella nadie puede borrar ni cambiar tus archivos. Si la pierdes, revócala en la misma página de GitHub.
